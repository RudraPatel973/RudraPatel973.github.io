# Rudra Patel Portfolio

Personal portfolio featuring my experience, education, skills, Greet-ly, Volution, and honours thesis.

Live website: https://rudra-patel-portfolio-lemon.vercel.app/

## Files

- `index.html`: page layout and content.
- `portfolio.css`: responsive styling, themes, and reduced-motion-aware animations.
- `portfolio.js`: interactive features and terminal commands.
- `terminal.html`: terminal view.
- `greetly-demo.html`: Retell voice demo used inside the phone-shaped popup.
- `assets/`: the images, logos, illustrated map, and resume used by this website.
- `vercel.json`: hosting headers and configuration.

## Run locally

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Font/icon styles and the official Retell widget require an internet connection. Voice calls require microphone access and the Retell public key/agent configuration to allow the site's origin. No private API keys are included.

## Deploy

Import this repository into Vercel as a static site, with the repository root as the project directory and no build command. The existing production site remains deployed separately until its Git connection is configured.

This repository contains only Rudra's portfolio files and its referenced assets, excluding the original reference website's code and unused assets.
